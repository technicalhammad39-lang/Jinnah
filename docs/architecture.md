# Architecture & Tech Stack

## Overview
This project is a modern, high-performance e-commerce frontend built for "Jinnah Hardware Store". It utilizes a cutting-edge React ecosystem for delivering a premium user experience with advanced animations and responsive design.

## Core Technologies
- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS 4, PostCSS
- **Animations:** GSAP (GreenSock Animation Platform), Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## Directory Structure
- `/app`: Next.js App Router pages and layouts (`page.tsx`, `layout.tsx`, `/shop`).
- `/components`: Modular React components divided by feature (`animations`, `hero`, `navigation`, `products`, `sections`).
- `/context`: React Context for global state (`AppContext.tsx`).
- `/data`: Hardcoded data models and initial mock data (`products.ts`).
- `/hooks`: Custom React hooks (`use-mobile.ts`).
- `/lib`: Utility functions (`utils.ts`).
- `/docs`: Project documentation.

## Key Features
- **Responsive Design:** Built mobile-first using Tailwind CSS.
- **Dynamic Routing:** Utilizes Next.js App Router.
- **Advanced Animations:** Custom cursors, interactive backgrounds, and marquee sections using GSAP/Motion.
